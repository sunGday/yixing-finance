# 视觉决策（web）

只读财务台。结构参考常见广告消耗 / 财务总览的信息层级（KPI 主次、吸顶筛选、紧表、桌面侧栏 + 移动底栏、对账队列）。未复制任何第三方仓库的代码、样式表或素材。

## 布局

- 桌面：固定深色侧栏（宽 224px）+ 浅色内容画布。侧栏不随主题变浅，用来托住导航。移动（<768px）：隐藏侧栏，底栏四项（概览 / 充值 / 收入 / 对账），触控高度 56px，含安全区。
- 筛选条吸顶，高约 32–36px，快捷日期做成一段分段控件，而不是四颗散按钮。移动端收进底部 Sheet，条上只留已选 chip。
- 页头一行：标题、区间、单位、数据源、只读标记。单位每页只在页头写一次。

## 层级

- 主指标用 28–32px tabular 数字（概览「充值合计」、收入「净收入」、对账「差额合计」）。
- 次指标 18–22px。异常（未匹配、差额 ≠ 0、部分匹配）用状态色描边，文字 chip 同时出现，不只靠颜色。
- 表：13px 正文、12px 表头、行高约 36px、表头与合计在表区域内吸顶/吸底。金额右对齐。

## Token

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#f3f4f6` | `#0c1016` | 页面底 |
| `--surface` | `#ffffff` | `#151b24` | 卡片 / 表 |
| `--surface-sunken` | `#f4f6f8` | `#1c2430` | 表头、合计 |
| `--text` / `--text-muted` | `#1a1d23` / `#6b7280` | `#e7edf5` / `#93a0b4` | 正文 / 辅助 |
| `--brand` | `#2563eb` | `#60a5fa` | 唯一强调：选中、焦点、链接 |
| `--success` | `#15803d` | `#4ade80` | 已匹配、已过账、已结算 |
| `--warning` | `#b45309` | `#fbbf24` | 部分匹配、预估 |
| `--danger` | `#dc2626` | `#f87171` | 未匹配、错误、差额 ≠ 0 |
| `--info` | `#0369a1` | `#7dd3fc` | 非关账、说明 |
| `--side` | `#12161e` | `#0a0d12` | 侧栏，不跟内容表面走 |
| `--radius` | `8px` | 同左 | 卡片 |
| 图表 | `#2563eb` / `#93c5fd` | 同系 | 充值 / 消耗，穿山甲 / 优量汇 |

深色由侧栏或移动筛选条的「深色 / 浅色」切换，写入 `localStorage` 键 `yx-theme`。首屏用一段内联脚本在绘制前加上 `class="dark"`，避免闪白。

字体：`system-ui`、`"PingFang SC"`、`"Noto Sans SC"`、`"WenQuanYi Micro Hei"`。金额 `.num` 使用 tabular-nums。流水号 `.mono`。

## 金额

- 存储与计算用整数分。`formatFen` 默认 ÷100，两位小数，千分位。`null` 显示「—」，不补 0。
- 扣回、冲正、带符号差额用 `−` / `+`。红色只给差异和错误，不给普通负数。

## 性能

- Pages 默认把 fixtures 打进对应路由的客户端包，首屏 HTML 即含默认筛选下的数字，不发接口。
- `next dev` / `next start` 默认 `NEXT_PUBLIC_FINANCE_MODE=live`，请求 `/api/v1`。`build:pages`（`STATIC_EXPORT=1`）强制 `fixtures`，不注入该 base。`?mock=1` 仍切样例。`api-client` 只在 live 时动态导入。
- 不引入图表库。柱和占比是路由内的小 SVG / div。
- 对账抽屉、表、Sheet 只在 `/reconcile` 路由包里。根布局只有壳和筛选。
- 路由切换保留 `loading.tsx` 骨架。

## 明确不做

- 不放录入、调账、关账、重跑对账按钮。
- 来源标签（人工 / OMNI 等）用中性描边，不另配色。
