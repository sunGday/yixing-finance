## 移动（底栏「对账」）
- 首屏：KPI + **仅** unmatched/partial 卡片（matched 折叠入口）
- 卡：scope · 日期 · delta 大字 · status chip → 全屏 sheet 明细
- 筛选：日期快捷 + 状态 + 子户；网络筛选在收入 Tab 才强调
